# Flight Information Region boundaries

`firs.json` holds 1,121 FIR/sector boundaries with their ICAO names, derived from
the [VAT-Spy Client Data Update Project](https://github.com/vatsimnetwork/vatspy-data-project)
(`Boundaries.geojson` joined with the `[FIRs]` table in `VATSpy.dat`). Coordinates are
rounded to 0.01°.

published FIRs but are **not an authoritative aeronautical source** and must never
be used for navigation.
