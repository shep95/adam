# Country outlines

`countries-50m.json` is the 1:50m TopoJSON from
[world-atlas 2.0.2](https://github.com/topojson/world-atlas) (ISC), itself
built from [Natural Earth](https://www.naturalearthdata.com/) admin-0
countries (public domain). Used by `src/intel/countryLookup.js` to place
points (satellite heat detections) in a country.

Country boundaries follow Natural Earth's de facto conventions and do not
imply any position on disputed territory.
